# 就活情報共有サービス

## 概要

「就活で得た情報を、次の就活生につなぐ」をコンセプトにした、
就活情報共有サービス・就勝つ掲示板です。

就職活動中に得た企業情報や面接情報を投稿・検索でき、
他の就活生が必要な情報を探しやすくすることを目的として開発しました。

## 主な機能

- ユーザー新規登録
- ログイン・ログアウト
- 就活情報の投稿
- 投稿一覧の表示
- 企業名による検索
- カテゴリによる検索
- 自分の投稿の編集
- 自分の投稿の削除
- 編集・削除時のパスワード確認
- 投稿者情報の表示
- 投稿日時の表示

## 使用技術

- PHP
- MySQL
- HTML
- CSS
- PDO

## データベース

### usersテーブル

| カラム | 内容 |
|---|---|
| id | ユーザーID |
| name | 名前 |
| email | メールアドレス |
| password | パスワード |

### postsテーブル

| カラム | 内容 |
|---|---|
| id | 投稿ID |
| user_id | 投稿者ID |
| company | 企業名 |
| category | カテゴリ |
| title | タイトル |
| comment | 投稿内容 |
| created_at | 投稿日時 |

## 工夫した点

投稿者本人だけが自分の投稿を編集・削除できるように、
ログイン中のユーザーIDと投稿者IDを照合しています。

また、編集・削除時にはパスワードを確認することで、
本人以外が操作できない仕組みにしています。
